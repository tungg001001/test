GitHub 網站架設教學

從申請 GitHub 帳號開始， 一步一步建立自己的網站， 最後使用 GitHub Pages 免費發布。

開始學習

🚀 開始之前

GitHub 不只是放程式碼的平台， 也可以利用 GitHub Pages 建立自己的網站。

需要準備：
  • 一個 Email
  • 一個 GitHub 帳號
  • 一個瀏覽器
  • HTML 基本程式碼

📚 完整架站流程

1

申請 GitHub 帳號

前往 GitHub 官方網站， 點選 Sign up 建立帳號。

GitHub： https://github.com/

2

驗證 Email

到自己的信箱尋找 GitHub 寄出的驗證信，完成 Email 驗證。

3

建立 Repository

登入 GitHub 後， 點選： 

＋ → New repository
4

設定 Repository 名稱

如果要建立個人網站， Repository 名稱使用： 

你的帳號.github.io

例如：

esp32master.github.io
5

建立 index.html

在 Repository 裡建立： 

index.html

這個檔案可以作為網站首頁。

6

上傳網站程式

將 HTML、CSS、JavaScript 等檔案放入 Repository。

7

開啟 GitHub Pages

進入： 

Settings
   ↓
Pages
   ↓
Build and deployment
   ↓
Deploy from a branch
   ↓
main
   ↓
/ (root)
8

等待 GitHub 部署

GitHub 會自動建立網站。 完成後即可取得網站網址。

9

開啟你的網站

網址格式： 

https://你的帳號.github.io/

💻 HTML 網站範例

例如你的首頁可以使用以下程式： 

<!DOCTYPE html>

<html lang="zh-TW">

<head>

    <meta charset="UTF-8">

    <title>我的 GitHub 網站</title>

</head>

<body>

    <h1>歡迎來到我的網站</h1>

    <p>
        這是一個 GitHub Pages 網站。
    </p>

</body>

</html>

📁 GitHub 網站資料夾架構

你的帳號.github.io │ ├── index.html │ ├── css/ │ └── style.css │ ├── js/ │ └── script.js │ ├── images/ │ ├── logo.png │ └── photo.jpg │ └── README.md
